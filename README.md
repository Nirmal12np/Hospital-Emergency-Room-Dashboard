# Hospital-Emergency-Room-Dashboard
Interactive Hospital Emergency Room Dashboard built in Power BI to analyze patient flow, admissions, waiting time, satisfaction, demographics, and referrals. Used Power Query and DAX for data cleaning, transformation, KPI creation, and interactive visualization.



Hospital Emergency Room Dashboard | Power BI

 Project Overview

The **Hospital Emergency Room Dashboard** is an interactive **Power BI data analytics project** designed to analyze hospital emergency room operations and patient-related data.

The dashboard provides insights into **patient volume, admissions, waiting time, patient satisfaction, demographics, referrals, and department performance**, helping identify operational trends and improve decision-making.

 Project Objectives

* Analyze overall emergency room patient volume.
* Monitor patient admission and non-admission trends.
* Analyze average patient waiting time.
* Evaluate patient satisfaction levels.
* Understand patient demographics and age groups.
* Analyze department-wise patient referrals.
* Identify operational trends and performance patterns.
* Present healthcare data through an interactive dashboard.
